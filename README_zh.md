# 仓颉VSCode插件

[View English](./README.md)

仓颉编程语言是一种面向全场景应用开发的通用编程语言，可以兼顾开发效率和运行性能，并提供良好的编程体验。开发者能使用仓颉VSCode插件进行仓颉语言开发。

本仓库存放仓颉VSCode插件开发指导。

## 简介

提供使用仓颉VSCode插件进行仓颉代码的开发指导，包括语言服务、编译构建、调试服务以及工具指导。
