# Cangjie VSCode Plugin

[查看中文](./README_zh.md)

The Cangjie programming language is a general-purpose programming language designed for full-scenario application development. It balances development efficiency with runtime performance while delivering an excellent programming experience. Developers can use the Cangjie VSCode extension for Cangjie language development.

This repository contains development guidelines for the Cangjie VSCode extension.

## Introduction

Provide development guidelines for Cangjie code using the Cangjie VS Code extension, including language services, compilation and building, debugging services, and tool guidance.

Plugin Download Link: [VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=IDE-Innovation-Lab.cangjie)
